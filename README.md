## Updating the profile

Everything on the page comes from [`data/profile.json`](data/profile.json).

1. **Visual editor:** open https://ashfaq1306.github.io/edit.html, make changes, click *Preview*, then *Publish*.
   Publishing needs a GitHub fine-grained token for this repository only, with *Contents: Read and write*.
2. **On GitHub:** edit `data/profile.json` in the browser and commit. The site redeploys in about a minute.

New public GitHub repositories appear automatically under "Live from GitHub". To hide one, add its name to `github.exclude`.
